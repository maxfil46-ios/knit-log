# KNIT.LOG — локальная версия

## Возможности этой сборки
- Каталог изделий и фильтры по статусу.
- Добавление и редактирование изделий.
- Несколько фотографий на изделие: оригинал и уменьшенная копия для каталога.
- Удаление изделия с подтверждением; связанные заметки удаляются вместе с ним.
- Профили людей: добавление, редактирование и удаление.
- При удалении человека связанные изделия сохраняются, привязка к профилю снимается.
- Параметры вязания и заметки, отображаемые в карточке изделия; заметки можно удалять.
- Локальное хранение записей и фотографий в IndexedDB.
- Экспорт/импорт резервной копии, включая фотографии.

## Важно
Это локальная версия: данные хранятся в браузере на одном устройстве. Облачная синхронизация между компьютером и телефоном ещё не подключена. Не очищайте данные сайта/браузера, иначе локальные записи могут быть удалены.

Для обновления заменяйте файлы приложения, но не очищайте данные браузера. Если открывали старую версию с Service Worker на веб-сервере, закройте приложение и перезагрузите страницу; новая сборка использует новый номер кеша.
